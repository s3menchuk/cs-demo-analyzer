# CS2 radar assets

Radar textures and overview configuration are game assets owned by Valve Corporation.
Downloaded from [MurkyYT/cs2-map-icons](https://github.com/MurkyYT/cs2-map-icons),
revision `9a77417b108eab6ee8c10d1140d62c0b77f54174`.
The repository extracts the radar images and matching overview data from the CS2 game depot.
These assets are included locally so the application works without an external image service.
Radar layouts reflect that snapshot of the game and can differ from older demo versions.

To refresh the pinned assets, edit the revision in `scripts/fetch_maps.py` and run it.
